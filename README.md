# IoT-Based Smart Home Energy Saver System

## SDG Goal
SDG 7 – Affordable and Clean Energy

## Objective
To reduce electricity wastage by automatically controlling appliances based on room occupancy.

## Hardware Components
- ESP32 Microcontroller
- PIR Motion Sensor
- Relay Module
- LED Bulb / Light

## Features
- Motion Detection
- Automatic Appliance Control
- Energy Saving Alerts
- Real-Time Dashboard Monitoring

## Technologies Used
- HTML
- CSS
- JavaScript
- Arduino IDE
- ESP32
- Firebase Realtime Database
- GitHub
